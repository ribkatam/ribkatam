### What I work on

**Real-time and distributed services.** I built and operated the backend for a production assistive
communication product: WebRTC audio transport, WebSocket streaming, asynchronous background processing
with retries and idempotent handling, a MongoDB data layer, and deployment on GCP. I owned it from API
design through incident response.

**Systems correctness.** I go into large codebases to find out why something is wrong. My thesis work
turned up a conductance defect in a simulator's CPU execution path that caused divergence from its GPU
backend, proportional to node in-degree. Finding it meant reading the C++ and CUDA source.

**Measurement that holds up.** I designed the four-term objective my research was evaluated against
after showing the obvious single-number measures could be satisfied by degenerate behavior. A metric
that can be gamed is worse than no metric.
